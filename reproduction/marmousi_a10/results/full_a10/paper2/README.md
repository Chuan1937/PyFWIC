# 方法论文的 Marmousi 补充结果

这些图用 PR 中已经提交的 A10 计算结果生成。读取 DV 的两期最终模型后，基线期按论文式 (17) 逐点估计孔隙度、黏土含量和含水饱和度。监测期固定基线估计的孔隙度和黏土含量，只拟合饱和度。拟合使用物理上下界，各弹性残差用特征量归一化，具体参数见 `indirect.py`。时移量统一为监测期减去基线期。

| 含水饱和度变化的相对 L2 | DV 间接 | PCS 直接 |
| --- | --- | --- |
| 全域 | 52.1% | 56.2% |
| 左储层 | 51.2% | 61.2% |
| 右储层 | 40.6% | 24.7% |

两条路线都恢复了左右储层的符号。左侧真值为 +0.20，DV 间接和 PCS 直接估计的最大值分别约 +0.131 和 +0.110。PCS 在右侧储层内误差更低，DV 间接在左储层和全域的误差更低。该结果使用 PCS 转换真值合成的共享炮集与当前 PR 的反演设置。论文的横向正则、式 (6) 梯度缩放和原始弹性输入差异仍需单独对齐。

参考 [Mardan 等，2023，Geophysical Prospecting](https://doi.org/10.1111/1365-2478.13363)。
